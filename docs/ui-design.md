# 界面设计：雾林 · 轻透

保留本地森林壁纸、搜索、快捷入口和右下角工作区的使用方式，以更安静的色彩、留白与轻透材质建立层次。不引入新的运行时依赖、外部字体或远程设计资源。

## 视觉规范

- **首页层次**：左上角轻量品牌、右上角磨砂工具栏；居中的大字号时钟和日期；搜索栏、快捷入口和胶囊式页码依次排列。
- **色彩**：以鼠尾草绿作为操作强调色；内置工具使用固定的柔和彩色底与线性图标。网站入口保留原来的品牌图片或自定义图标。
- **材质**：搜索、Dock 和小组件使用半透明背景与轻量背景模糊；弹窗与设置卡片使用实色表面，保持表单可读。
- **设置面板**：桌面使用悬浮圆角侧栏，手机端使用全屏面板；分区导航固定在标题下方，设置项按卡片分组。
- **控件**：开关保留原生 checkbox 的标签、焦点与空格键操作；壁纸同时通过边框、勾选标记和 `aria-pressed` 表达当前选择。

主要语义色板位于 `src/styles/main.css` 的 `:root` 与 `.theme-dark` 中：

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--ui-accent` | `#467d68` | `#528970` | 主操作、开关、滑杆 |
| `--ui-accent-text` | `#3e755e` | `#a2d1b8` | 强调文字 |
| `--ui-surface` | `#ffffff` | `#222d25` | 卡片、菜单、弹窗 |
| `--ui-panel` | `#f3f6f3` | `#19231d` | 面板底色 |
| `--ui-text` | `#2c3d34` | `#e0e9e2` | 主要文字 |
| `--ui-muted` | `#637368` | `#a0afa5` | 次要文字 |

设置分区、搜索操作、选中标记和菜单动作复用现有 `@lucide/vue` 图标库，使用一致的线条与对齐；网站品牌图片和用户上传图标不作替换。

### 下拉框与操作菜单

- 表单和设置中的选择框统一使用 `SelectField`，共用高度、边框、圆角、主题色和 Lucide 下拉指示；无障碍名称、数值选项、禁用状态及键盘交互仍由原生 `select` 承载。
- 支持 `appearance: base-select` 的浏览器将选项展示在顶层，避免被滚动容器截断，并按视口限制宽高；选中项有强调背景与勾选。浅/深色主题共用语义 token。
- 不支持增强样式时保留原生选择菜单；强制高对比度模式退回系统外观。展开时按 Escape 只收起选择菜单，不连带关闭设置或表单。
- 搜索引擎仍使用已有的可访问列表框，不重写其搜索/键盘行为；快捷入口、Dock、工作区操作菜单统一间距、焦点和危险操作色，支持上下循环、Home/End 与禁用项跳过，Escape 恢复触发点焦点。
- 工作区重命名时，鼠标移出不会收起仍有焦点的输入框；提交后聚焦原标签，键盘焦点与鼠标都离开后才延迟收起，避免操作菜单关闭引发的 focusout 误收起仍被鼠标悬停的控件。

### 快捷入口表单

- 新建／编辑保留同一套「雾林」语义色，先填写名称、网址、工作区；原生披露控件承载可选的图标与外观，折叠状态也有本地预览。
- 使用原生模态 `dialog` 隔离背景，保持关闭按钮、标题和保存区可见，仅字段内容区滚动。输入与操作控件至少 44px；窄屏／粗指针输入为 16px，避免依赖 hover。
- 错误文案关联具体字段，聚焦首个错误；图片处理中保留退出路径和稳定状态提示。表单不播放入场位移，按压反馈尊重键盘与减少动态效果设置。
- 编辑器中可读性优先于透明材质，深色主操作、边界与焦点使用局部语义色覆盖，不改变用户自选的图标配色或首页主题。
- [本轮 skill 应用记录](ui-skill-refinements.md)列出 Jakub Krehel／Emil Kowalski 的固定参考版本、Before / After / Why、实测对比度、截图以及未覆盖的环境。

### 分页与布局稳定性

- 仅保留分页圆点，当前页为短胶囊，不显示左右箭头。仍可点击圆点、使用左右方向键、滑动和触控板切换。
- 快捷入口网格按当前工作区最满一页计算预留行数，同一布局中所有页面使用相同行高；只有一项的末页也不会将页码向上推。单页内容较少时不会无谓预留整页空白。
- 预留行数随列数、窗口和工作区变化重新计算；微粒消散、光迹拖尾、平滑滑动沿用既有过渡与循环机制。

内置工具的 SVG 图标映射集中在 `src/components/launcherIcons.ts`，供快捷入口与 Dock 共用；颜色按工具 ID 绑定，拖动排序不会改变图标颜色。

### 本地查找：范围、位置与下一步

参考同类开源项目的分组、搜索和轻量工作流，但只增强已有能力；固定提交与取舍记录见 [`product-reference-audit.md`](product-reference-audit.md#开源同类项目从参考到设计2026-11-20)。

- **清楚的边界**：右上角放大镜或 `Ctrl/⌘+F` 打开本地入口查找；默认当前工作区，可切换全部工作区。范围选择只在本次查找中生效，不改变保存的偏好；无结果的 Enter 不会触发网页搜索。
- **可理解的相关性**：名称精确匹配、前缀、名称包含、网址、位置依次排序；等分保留当前工作区优先和原入口顺序。支持全角/半角兼容字符与多个空白分隔词，名称、网址、文件夹和工作区信息均可参与查找，内置工具不借工作区名匹配。
- **位置可见**：每条结果用统一线性工具/文件夹图标或网站首字标识，主标题与次要位置/网址分层。异地结果标明所属工作区，点击后切换到该工作区再执行原打开操作；保留网站打开偏好和修饰键/中键行为。
- **有下一步的空状态**：无输入时说明查找范围，无结果时建议修改关键词或范围，并提供添加快捷入口、创建文件夹两项现有操作。对话框关闭后回到右上角触发按钮；原本隐藏的搜索栏重新收起。
- **连续的键盘操作**：输入框按 `↓` 进入首条，结果支持 `↑`、`↓`、Home、End，首条按 `↑` 返回输入框，Enter 打开，Escape 返回网页搜索；输入法选词不触发查找提交或方向键跳转。底部提示与范围工具栏不随结果列表滚走。
- **受控的长度和滚动**：先显示 12 项，按需每次再显示 12 项；总数明确，不截断搜索范围。弹层根据视口上下空间放置，最高 440px，结果列表独立滚动，不触发主页翻页。关键词最长 200 个输入字符，不持久化、不发送到网络。

### 可操作的待办概览

- 保留前两项未完成任务与总数，标题继续打开完整待办面板；复杂编辑、筛选和删除留在面板中。
- 首页可用原生 checkbox 完成任务，用紧凑输入框添加，用单次撤销恢复最近完成的一项；完成后聚焦下一项，最后一项完成后聚焦撤销，撤销后聚焦恢复的任务（不在预览中时聚焦输入框）。
- 空白内容不可提交，达到既有 500 项上限时禁用新增；输入法 Enter 确认候选字不会新增。操作使用独立 live status 提示，任务标题省略时保留完整标题。
- 复用工作区的待办操作和本地存储，与面板、其他标签页及备份保持一致；其他标签页删除或重新打开该任务后，不再显示过时的撤销按钮。撤销不是持久历史，刷新或移除组件后不保留。

## 响应式与兼容

- 桌面主区域最大宽度为 1040px，初始快捷图标为 72px、圆角 22px，搜索栏为 600 × 56px。仅改变初始默认值，不迁移或覆盖已有本地偏好。
- 宽度不超过 780px 时最多显示五列，不超过 480px 时最多显示四列；翻页容量与显示列数同步。保存的桌面列数不变，窗口变宽时自动恢复。
- `App.vue` 同时计算时钟占用空间、图标适配尺寸和内容顶部留白，再以 CSS 变量传给样式，避免计算与渲染不一致。
- 低矮视口缩小时钟；高度不超过 560px 时隐藏时钟。启用小组件时允许首页自动滚动，月历等高卡片不会截断快捷入口；启用 Dock 的短屏也可滚动。
- 设置分区导航按实际标题高度定位，不再假设固定的旧标题尺寸；搜索引擎菜单按实际宽度约束到视口内。
- 保留系统减少动态效果的支持；高对比度模式下，开关退回原生 checkbox 外观。既有快捷键、对话框焦点管理和按需加载不变。

## 回归检查

`e2e/ui-refinements.spec.ts` 验证三种效果 × 桌面/手机/短屏的满页与单项末页几何一致性、无箭头分页、浅深色下拉框不溢出、分层 Escape、原生键盘与强制高对比度回退、菜单焦点，以及打开方式的保存/备份与导航。

`e2e/appearance.spec.ts` 使用布局尺寸和语义断言，而非依赖机器字体的像素快照，覆盖六种视口、列数切换和偏好保留、设置导航、键盘开关及深色的 Teleport 菜单。

`e2e/discovery.spec.ts` 覆盖当前/全部工作区查找、相关性、位置、异地打开与持久化、修饰键/中键、输入法、空状态创建与焦点、浅/深色桌面/手机/短屏的边界与独立滚动，以及首页待办的新增、完成、撤销、面板共享和跨标签页同步。`e2e/production-chunks.spec.ts` 另行验证生产环境按需请求、加载中的 Enter 和加载失败恢复，防止分组代码提前请求或加载失败使首页不可用。

```sh
npm run verify
npm run test:e2e:production
```

原有功能、焦点、触屏排序与滚动、生产分块失败恢复和构建体积预算继续由既有测试保护。
