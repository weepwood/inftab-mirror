# Skill 驱动的 UI 与交互细化 · 2026-11-20

## 范围与依据

本轮实现聚焦 **新建／编辑快捷入口** 的完整流程：打开、填写、外观调整、校验、图片处理、保存／取消和焦点恢复；另修复全量回归中复现的工作区菜单延迟收起问题。不改首页「雾林」视觉方向，不重写搜索、分页、工作区数据或备份协议，也不将本轮描述为全站审计。

沿用 Vue 3、TypeScript、共享 CSS、系统字体和 Lucide 图标。约定来自 [`ui-design.md`](ui-design.md)、[`implemented-features.md`](implemented-features.md) 和 README；仓库没有 `AGENTS.md`。没有新增运行时依赖、远程字体或设计资源。

参考用户指定的两个 MIT skill 仓库，固定到本轮读取的提交，而非随上游浮动：

- [jakubkrehel/skills](https://github.com/jakubkrehel/skills/tree/672ae44ace6aaed65b86cbb1e2fd6fbea0e79578)：`better-interface`，以及 accessibility、layout、writing、typography、colors、ui、motion 七个领域。采用有证据再修改、尊重现有规范、原生控件优先、字段错误关联、渐进披露和测量对比度的做法。
- [emilkowalski/skills](https://github.com/emilkowalski/skills/tree/64eb3deb9a5fbfa041faf783e0bc3fd635872e9c)：`emil-design-eng`、`animation-performance` 和 UI cheatsheet。采用高频操作减少动效、明确过渡属性、指针与键盘区别处理、触屏 hover 隔离和合成属性优先的做法；没有为此引入 Motion 或其他动画库。

skill 源码仅下载到忽略的研究缓存中，作为设计参考；没有安装全局指令，也没有将上游脚本作为项目运行时执行。

加载外壳留在 `App.vue`，表单逻辑移入懒加载 `ShortcutEditor.vue`。相关快捷入口／文件夹／确认编辑器合并为 `local-editors` 可选分块，仅在使用时下载，不挂载同组的其他组件。计算器的私有解析器并入原有工具分块，避免多余的循环 facade 请求；预算没有放宽。

- 严格 E2E／Playwright 配置类型检查通过；生产依赖 `npm audit --omit=dev --audit-level=moderate` 为 0 个漏洞。
- `e2e/shortcut-editor.spec.ts`：覆盖响应式／主题、实测对比度、原生模态隔离、键盘、输入法、原生选择框、输入校验、本地预览／上传／清除、取消不保存、200% 根字号、强制高对比度、触屏和减少动态效果。
- `e2e/production-chunks.spec.ts`：额外验证编辑器不提前下载、加载期间仍可退出、加载失败可关闭并显式刷新恢复。

## 保持的产品契约

- 只有分页圆点、没有左右箭头；末页不足时圆点位置不变。
- 既有 `SelectField` 增强菜单、原生回退及 Escape 分层行为保留。
- 名称 80 字符、网址安全校验、500 项上限、Unicode 图标文字、工作区归属与文件夹关系仍由原有数据操作校验。
- 网站版在明确保存时下载远程图标；扩展版保留图片 URL，不扩大主机权限。本地上传依然压缩后保存，图片处理仍按需加载。
- 草稿不新增存储键、不修改备份格式；既有打开方式、本地数据、跨标签页同步不变。
- 使用 `closedby="any"` 的原生轻量关闭在支持它的浏览器启用；未支持此属性的浏览器仍能用取消、关闭按钮或 Escape 退出。
