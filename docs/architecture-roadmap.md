# 架构演进路线

## V1.1 第一批
- 提取首页布局、页面导航、快捷入口分页、拖拽与粒子动画、生产力业务操作。
- 同步存储适配器保留所有 v1 键及 JSON 格式；不执行破坏性迁移。
- CI 一次构建，复用 dist 进行三类生产测试；保留独立本地测试命令。
- 首屏 JS gzip 上限仍为 60.5 KiB；全部 JS 的独立上限为 156 KiB，避免仅因非首屏模块拆分而阻断构建。

## V1.1 第二批
- 将快捷入口、文件夹和工作区命令提取至 workspaceLauncher；将备份快照及合并/覆盖导入提取至 workspaceBackup。
- 独立跨标签工作区所有权合并、旧默认快捷入口迁移；保持 v1 格式及现有同步顺序。
- 修复快捷入口拖至自身时可能错误排序；增加快照隔离、旧天气配置及排序回归测试。

## V1.1 收尾与候选版本
- 忽略损坏的跨标签 JSON 事件，不取消待保存的本地编辑；写入失败保留待写标记，在页面离开/隐藏/作用域销毁时尝试恢复，不做无限重试。
- 增加失败恢复测试和版本一致性校验；保持 localStorage v1 与备份 v1，暂不迁移 IndexedDB（避免无收益的数据迁移风险）。
- 版本号统一为 1.1.0，合并里程碑发布说明后自动启动完整 Release validation。仅在验证成功后视为正式验收。

## V1.2 视觉基础（候选）
- 语义颜色、玻璃表面、圆角、焦点、动效 token 独立，保留原版雾林视觉，增加岩灰、靛蓝、暖砂配色；颜色模式与配色独立。
- 新增按需加载的命令面板（Ctrl/⌘+Shift+P），支持键盘查找、选择与执行；保留 Ctrl/⌘+K 的原有搜索行为。
- 旧偏好缺少配色字段时仍默认雾林；版本号和备份格式暂不变。后续完善共享浮层、触屏与视觉回归，再进行 V1.2 正式验收。

## V1.2 浮层与输入体验
- 共享浮层键盘焦点循环，排除隐藏/禁用/折叠元素；命令、文件夹、确认、设置及入口编辑遵循统一键盘规则。
- 中文输入法组合期间不执行命令或误关闭浮层；浮层开启时禁止首页滑动翻页及滚轮拦截，触屏命令列表局部滚动。
- 增加配色持久化、命令面板焦点、移动端尺寸及减弱动效的浏览器视觉契约测试（非像素快照）。

## V1.2 收尾与候选版本
- 配色备份兼容旧 v1 格式；拒绝未知配色，增加导入导出回归测试。
- 正式版本号统一为 1.2.0，保留原有扩展权限与性能预算。
- 为浮层核心模块与视觉契约新增独立专项浏览器验证，仅指定路径变更时触发或手动执行，不重复全量 E2E。

## V1.3 第一批：工作区独立布局
- 每个工作区可单独设置列数、行数、图标尺寸、圆角、名称可见性；未配置时继承全局，移动端仍受响应式上限约束。
- 工作区菜单增加布局编辑、保存、跟随全局，保持既有全局设置行为。
- 布局字段随工作区 v1 备份保存；旧备份合并时保留现有布局，覆盖导入按备份恢复。跨标签布局与成员变动独立保留，同一布局冲突远端优先。
- 修正 1.2.0 锁文件中两个未实际升级的间接依赖版本元数据，保持原有下载地址及完整性哈希。

## V1.3 第二批：入口管理与本地恢复
- 设置的数据分区提供懒加载入口管理，支持名称/网址/标签筛选、批量选中、移动、删除、添加/移除标签；移动/删除先保存恢复点。
- Netscape HTML 书签预览、无效协议/重复/上限过滤、确认后导入当前工作区（目录展平）；导出按工作区及文件夹组织。
- IndexedDB 保存本机恢复点，打开首页时每日最多一次，手动及变更前快照，最多 7 条/24 MiB；恢复前验证并保留当前快照。不等于跨设备备份。
- 新增数据管理专项浏览器验证：真实 HTML 预览、标签、本地 IndexedDB 恢复点、批量删除与恢复、HTML 下载；只在高风险数据模块变动时触发。
- 首屏 JS gzip 上限由 58.5 KiB 微调至 60.5 KiB，全部 JS 上限由 140 KiB 调整为 156 KiB；新管理工具、HTML、历史均按需加载，真实构建结果以 CI 为准。

## V1.3 第三批：首页布局与组件管理
- 通过工作区菜单或命令面板进入布局编辑器，草稿预览、取消、保存，检查工作区和布局是否被并发修改。
- 小组件目录搜索、启用/移除、预设、尺寸和排序统一管理；保留全局共享组件设置和原有权限策略，草稿预览不启动联网组件。
- 补充草稿隔离与浏览器布局、组件持久化测试；不提前升级版本号。
