# 架构演进路线

## V1.1 第一批
- 提取首页布局、页面导航、快捷入口分页、拖拽与粒子动画、生产力业务操作。
- 同步存储适配器保留所有 v1 键及 JSON 格式；不执行破坏性迁移。
- CI 一次构建，复用 dist 进行三类生产测试；保留独立本地测试命令。
- 首屏 JS gzip 上限仍为 58.5 KiB；全部 JS 的独立上限为 140 KiB，避免仅因非首屏模块拆分而阻断构建。

## V1.1 第二批
- 将快捷入口、文件夹和工作区命令提取至 workspaceLauncher；将备份快照及合并/覆盖导入提取至 workspaceBackup。
- 独立跨标签工作区所有权合并、旧默认快捷入口迁移；保持 v1 格式及现有同步顺序。
- 修复快捷入口拖至自身时可能错误排序；增加快照隔离、旧天气配置及排序回归测试。

## V1.1 收尾与候选版本
- 忽略损坏的跨标签 JSON 事件，不取消待保存的本地编辑；写入失败保留待写标记，在页面离开/隐藏/作用域销毁时尝试恢复，不做无限重试。
- 增加失败恢复测试和版本一致性校验；保持 localStorage v1 与备份 v1，暂不迁移 IndexedDB（避免无收益的数据迁移风险）。
- 版本号统一为 1.1.0，合并里程碑发布说明后自动启动完整 Release validation。仅在验证成功后视为正式验收。

## V1.2 视觉基础（候选）
- 语义颜色、玻璃表面、圆角、焦点、动效 token 独立，保留原版雾林视觉，增加岩灰、靛蓝、暖砂配色；颜色模式与配色独立。
- 新增按需加载的命令面板（Ctrl/⌘+Shift+P），支持键盘查找、选择与执行；保留 Ctrl/⌘+K 的原有搜索行为。
- 旧偏好缺少配色字段时仍默认雾林；版本号和备份格式暂不变。后续完善共享浮层、触屏与视觉回归，再进行 V1.2 正式验收。

## V1.2 浮层与输入体验
- 共享浮层键盘焦点循环，排除隐藏/禁用/折叠元素；命令、文件夹、确认、设置及入口编辑遵循统一键盘规则。
- 中文输入法组合期间不执行命令或误关闭浮层；浮层开启时禁止首页滑动翻页及滚轮拦截，触屏命令列表局部滚动。
- 增加配色持久化、命令面板焦点、移动端尺寸及减弱动效的浏览器视觉契约测试（非像素快照）。

## V1.2 收尾与候选版本
- 配色备份兼容旧 v1 格式；拒绝未知配色，增加导入导出回归测试。
- 正式版本号统一为 1.2.0，保留原有扩展权限与性能预算。
- 为浮层核心模块与视觉契约新增独立专项浏览器验证，仅指定路径变更时触发或手动执行，不重复全量 E2E。

## V1.3 第一批：工作区独立布局
- 每个工作区可单独设置列数、行数、图标尺寸、圆角、名称可见性；未配置时继承全局，移动端仍受响应式上限约束。
- 工作区菜单增加布局编辑、保存、跟随全局，保持既有全局设置行为。
- 布局字段随工作区 v1 备份保存；旧备份合并时保留现有布局，覆盖导入按备份恢复。跨标签布局与成员变动独立保留，同一布局冲突远端优先。
- 修正 1.2.0 锁文件中两个未实际升级的间接依赖版本元数据，保持原有下载地址及完整性哈希。

## V1.3 第二批：入口管理与本地恢复
- 设置的数据分区提供懒加载入口管理，支持名称/网址/标签筛选、批量选中、移动、删除、添加/移除标签；移动/删除先保存恢复点。
- Netscape HTML 书签预览、无效协议/重复/上限过滤、确认后导入当前工作区（目录展平）；导出按工作区及文件夹组织。
- IndexedDB 保存本机恢复点，打开首页时每日最多一次，手动及变更前快照，最多 7 条/24 MiB；恢复前验证并保留当前快照。不等于跨设备备份。
- 新增数据管理专项浏览器验证：真实 HTML 预览、标签、本地 IndexedDB 恢复点、批量删除与恢复、HTML 下载；只在高风险数据模块变动时触发。
- 首屏 JS gzip 上限由 58.5 KiB 微调至 60.5 KiB，全部 JS 上限由 140 KiB 调整为 156 KiB；新管理工具、HTML、历史均按需加载，真实构建结果以 CI 为准。

## V1.3 第三批：首页布局与组件管理
- 通过工作区菜单或命令面板进入布局编辑器，草稿预览、取消、保存，检查工作区和布局是否被并发修改。
- 小组件目录搜索、启用/移除、预设、尺寸和排序统一管理；保留全局共享组件设置和原有权限策略，草稿预览不启动联网组件。
- 补充草稿隔离与浏览器布局、组件持久化测试。
- 收尾：区分新建和编辑按钮的样式选择器，保留原创建与数量上限回归；仅修改组件时保留工作区原有部分覆盖字段，拒绝过时草稿；修复历史容量筛选边界。
- 候选版本统一为 1.3.0（仅包、根锁文件和扩展版本），加入根锁文件版本一致性检查，发布说明触发正式验收。

## V1.4 性能专项第一批
- 本地搜索按数据变化构建索引，连续输入和工作区范围变化复用规范化标题、URL、标签与上下文；固定五级评分桶保持原有排序，减少每次输入的重复排序和扫描。保留仅本地搜索、隐藏项及共享工具去重规则。
- 文件夹缩略图使用 ID 索引及缓存预览，找到四个有效入口后停止；数据管理列表缓存搜索文本、归属映射与 ID 集合，批量操作采用集合校验。
- 增加 500 个快捷入口 / 20 个工作区极限规模的功能回归；不将环境相关耗时断言作为日常合并门禁。实际性能与包体收益仍需测量，不增加预算。

## V1.4 性能专项第二批
- 分离内置、快捷入口、文件夹对象映射与排序；待办数量不变时不刷新入口集合，数量变更时复用原排序与其他对象。Dock 与隐藏项使用 Map/Set。
- 自动备份先在 IndexedDB 事务内检查每日标记，再按需生成/序列化快照；避免每日重复打开新标签页时复制完整工作台。手动与变更前快照仍保留原时间点，取消页面生命周期中的未完成自动快照。保留数据库 v1、快照限制和事务规则。
- 入口与文件夹图标采用异步解码，保留可见图标加载优先级；图标失败记录同时覆盖文件夹成员，避免无意义重试。不新增持久化图片缓存或网络权限。
- 新增自动备份跨标签互斥浏览器回归；实际性能收益待基准测量，预算不变。

## V1.4 性能专项第三批
- 翻页使用物理页索引作为稳定 DOM key，避免粒子页集合变化时复用错误页面；保留现有循环轨道和相邻页渲染规则。
- 每次粒子过渡复用一个采样画布，重置位图以隔离跨域图标；高 DPI 全屏画布上限 4 Mi 像素（RGBA8 约 16 MiB 单缓冲），普通屏幕保留原清晰度，不改粒子数量及动效时长。
- 新增 npm run benchmark:launcher：以 V1.3.0 原实现为基准，500 入口、20 工作区、20 文件夹、12 查询，验证结果等价并报告索引构建/查询批次 p50/p95。仅相关 UI 专项运行，无耗时硬阈值，不新增普通 PR 检查任务。
- 保持 60.5/156 KiB 预算不变，真实包体及测试结果待 CI；未宣称首屏体积下降。

## V1.4 实测与发布候选
- Actions 45378690939（43f6f6a）：500 入口、20 工作区、20 文件夹、12 查询、40 次采样；结果等价，原实现 P50/P95 9.309/11.303 ms，索引复用 0.813/1.266 ms，单次建索引 0.580/0.975 ms。仅代表该 Node 合成负载，不等于首页加载提速。
- Actions 45378690978：81 测试文件、663 单元/组件通过，首屏 JS gzip 59.8 KiB（V1.3 同为 59.8），全部 JS 150.3 KiB（V1.3 为 149.7），CSS 20.6 KiB；原预算 60.5/156 KiB 不变。首屏尚未进一步缩减，不夸大收益。
- UI 专项 24/24、数据专项 3/3 通过；版本号更新为 1.4.0 候选，前置 V1.3 的小视口修复及完整复验通过、同步 main 并重新验证后才合并。
- 后续 V1.5：自定义主题编辑、可验证的独立主题文件、预设管理、配置迁移（旧版兼容、预览、恢复点）。主题仅允许受控字段与值，不接受任意 CSS/脚本；不在 V1.4 混入新数据格式。

## V1.5 第一批：自定义主题与独立交换文件
- 设置外观中的懒加载编辑器提供浅/深色强调色、面板色、正文色、圆角、不透明度草稿预览；显式应用或恢复内置配色，拒绝过时草稿。
- 独立 inftab-theme v1 JSON 导入预览与导出（16 KiB），只允许六位十六进制颜色及有限整数，检查文字/表面与强调色/白字对比度 ≥4.5。透明背景实际对比度可能不同；旧浏览器无 color-mix 时使用不透明表面。
- 自定义字段可选，缺省旧备份合并保留现有主题；显式 null 禁用，覆盖恢复按备份配置。原 localStorage 与 JSON 备份版本不变，无新增权限或运行时依赖。
- 本批只覆盖语义 token 组件，不宣称全部遗留硬编码样式已迁移；多预设管理与选择性跨设备迁移待后续。新增单元/备份/浏览器专项测试，保留构建预算，实际结果待 CI。

## V1.5 第二批：预设库与选择性迁移
- 主题预设库最多 20 项，名称 40 字符，ID/名称去重；草稿保存、复制、重命名、二次确认删除、载入默认草稿。预设和当前主题独立，删除不影响当前配色；随旧版工作台备份可选字段保存，严格校验。
- 设置的数据分区提供选择性迁移：外观、全局布局、小组件、入口与工作区（含 Dock/文件夹/独立布局作为一组）。从已有 JSON 预览、选择、确认替换；保留未选配置与笔记、待办、习惯、纪念日、搜索引擎，完整快照先校验并备份，检测并发变更和组件销毁。
- 自定义主题下工作区面板接入语义 token，内置主题保持原样；新增预设与迁移单元/浏览器专项。仍待全面硬编码样式梳理和构建验证；现有性能预算不变。

## V1.5 第三批：一致性与交互收尾
- 同时修改同一主题时完整配色对象以远端版本为准，避免逐字段拼接产生无效对比度；无关设置仍合并。主题预设编辑器检测库变更，阻止过时草稿写回，允许重载。
- 自定义主题扩展至文件夹浮层、确认弹窗正文、快捷入口编辑器及共享按钮圆角、切换控件；仅在自定义主题启用时生效，保留原版内置视觉。
- 修复玻璃预览百分比表达式，新增跨标签浏览器回归与完整配色合并测试。V1.5 先以功能 PR 进入快速及专项验证，通过后再准备发布候选；预算不变。

- 收尾：应用/关闭主题时取消未完成的导入读取，主题冲突处理限定于主题对象与有 ID 的预设记录；将并发合并和主样式纳入 UI 专项路径。同步 main 后提交新改动触发 pull_request synchronize，等待最新 CI。
