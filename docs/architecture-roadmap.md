# 架构演进路线

## V1.1 第一批
- 提取首页布局、页面导航、快捷入口分页、拖拽与粒子动画、生产力业务操作。
- 同步存储适配器保留所有 v1 键及 JSON 格式；不执行破坏性迁移。
- CI 一次构建，复用 dist 进行三类生产测试；保留独立本地测试命令。
- 首屏 JS gzip 上限仍为 58.5 KiB；全部 JS 的独立上限为 140 KiB，避免仅因非首屏模块拆分而阻断构建。

## V1.1 第二批
- 将快捷入口、文件夹和工作区命令提取至 workspaceLauncher；将备份快照及合并/覆盖导入提取至 workspaceBackup。
- 独立跨标签工作区所有权合并、旧默认快捷入口迁移；保持 v1 格式及现有同步顺序。
- 修复快捷入口拖至自身时可能错误排序；增加快照隔离、旧天气配置及排序回归测试。

## V1.1 收尾与候选版本
- 忽略损坏的跨标签 JSON 事件，不取消待保存的本地编辑；写入失败保留待写标记，在页面离开/隐藏/作用域销毁时尝试恢复，不做无限重试。
- 增加失败恢复测试和版本一致性校验；保持 localStorage v1 与备份 v1，暂不迁移 IndexedDB（避免无收益的数据迁移风险）。
- 版本号统一为 1.1.0，合并里程碑发布说明后自动启动完整 Release validation。仅在验证成功后视为正式验收。

## V1.2 视觉基础（候选）
- 语义颜色、玻璃表面、圆角、焦点、动效 token 独立，保留原版雾林视觉，增加岩灰、靛蓝、暖砂配色；颜色模式与配色独立。
- 新增按需加载的命令面板（Ctrl/⌘+Shift+P），支持键盘查找、选择与执行；保留 Ctrl/⌘+K 的原有搜索行为。
- 旧偏好缺少配色字段时仍默认雾林；版本号和备份格式暂不变。后续完善共享浮层、触屏与视觉回归，再进行 V1.2 正式验收。

## 后续验收
- V1.1：完成 1.1.0 发布候选的完整浏览器、生产与扩展验证；通过后进入 V1.2。
- V1.2：语义 token、主题、共享浮层、命令注册表、动效与视觉回归。
- V1.3：独立工作区布局、布局编辑、批量入口和标签、备份快照、书签 HTML、小组件管理。
- V2.0：明确同步冲突策略、WebDAV 适配器、内置插件 SDK、网页离线、独立扩展包、跨设备迁移与主题交换。

日常 PR 必须通过快速 CI（类型、单元、生产构建和包校验）；每个正式里程碑版本发布前必须通过 Release validation 的完整浏览器、生产与扩展测试。高风险变更可提前运行针对性测试或手动全量验证。不覆盖已有用户配置，不提前发布版本号。
