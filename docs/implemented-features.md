# 已实现功能清单

这份清单按用户能力和运行环境整理当前版本，便于快速了解 Inftab 已能做什么，以及网站和 Chrome 新标签页扩展各自提供哪些能力。实现入口和开发注册方式见 [`plugin-development.md`](plugin-development.md)，端到端功能说明见 [README](../README.md)。

## 平台范围

| 能力 | 网站（Chrome、Edge） | Chrome MV3 扩展 |
| --- | --- | --- |
| 新标签页、搜索、快捷入口、工作区和内置面板 | 支持 | 支持 |
| 本地数据、设置、壁纸和 JSON 备份 | 按浏览器分别保存 | 按浏览器分别保存，可用备份迁移 |
| 天气与 Hacker News | 用户启用后联网 | 用户启用组件并点击授权后联网 |
| 书签、历史、当前标签页和常用网站 | 显示扩展专属能力说明 | 用户使用相应功能时按需申请权限 |
| 任意第三方插件代码 | 不支持 | 不支持 |

## 首页与快捷入口

- 响应式快捷入口网格，支持新建、编辑、删除、拖动排序、分页、图标上传、文件夹收纳和多工作区管理。
- 右上角提供直接新建和本地查找入口；默认查找当前工作区，可临时切换全部工作区。结果按名称相关性排序，支持全角字符、多词以及网址/文件夹/工作区匹配，显示位置和总数；每次显示 12 项，可继续展开。打开其他工作区的结果时才切换归属；隐藏入口不显示，共享工具不重复。
- 入口查找提供范围分段、键盘提示和无结果快速新建入口/文件夹，不会在无结果时转为网络搜索。隐藏搜索栏时可临时打开，退出后恢复；范围和关键词不持久化、不联网。结果列表独立滚动，不触发主页翻页。支持常驻 Dock；Chrome 扩展还可从当前窗口标签页或常用网站导入安全网址。
- 分页仅显示可点击的圆点，去掉左右箭头；网格按当前工作区最满一页预留行高，末页不足时圆点位置不变。保留键盘、滑动、触控板、拖动跨页和循环翻页。
- 网站、搜索结果、书签和历史记录有独立的新标签页打开开关；网站开关统一作用于网格、Dock、文件夹单项、入口搜索和常用网站组件，Ctrl / ⌘ / Shift 点击或鼠标中键仍可打开新标签页。文件夹“打开全部”始终使用多个新标签页。默认网站/书签/历史为新标签页，搜索为当前页。
- 支持本地时间显示、图标与网格布局调整、主题、壁纸上传、壁纸定时轮换，以及减少动态效果偏好。
- 首页小组件可固定、排序、调整宽度或移除；设置中提供“浏览发现”组件方案，一次启用天气、资讯、书签、历史和常用网站等发现类小组件。

## 搜索与内置工具

- 内置多个主流搜索引擎和网页、图片、新闻、视频、地图分类；支持添加自定义搜索引擎。
- 提供一键翻译搜索词、离线四则计算器，以及待办、习惯打卡、笔记、月历、纪念日和专注计时工具。
- 待办支持关键词与“全部 / 待完成 / 已完成”组合筛选；新增会显示新任务，编辑后恢复焦点，任务离开当前状态筛选时聚焦下一项。清除已完成仍针对全部记录，并保留删除确认。
- 首页待办概览可直接新增、完成和撤销最近一次完成，预览前两项未完成任务；与面板共用本地状态、500 项上限、备份和跨标签页同步。支持输入法、连续录入、操作提示与焦点衔接。撤销仅在当前组件存活且目标仍已完成时可用，不保存为历史记录。
- 笔记支持标题/正文搜索、默认/最近编辑/标题排序、搜索结果数量和正文字符计数；搜索不会替换当前编辑内容，新建会清除搜索并聚焦标题。列表工具栏在长列表滚动时保持可用，支持窄屏和深色主题。
- 待办和笔记的查找框优先用 `Esc` 清除非空搜索，再次按下才关闭面板。快捷入口搜索支持可见返回按钮、结果上下选择和从第一条结果返回输入框；删除确认结束后恢复焦点。
- 支持天气和 Hacker News 资讯。组件主动启用后才联网，显示来源；扩展还会在用户点击授权后申请对应的精确主机权限。资讯和天气会在可用时保留最近成功数据，并提供重试路径。
- 浏览器书签、历史和常用网站数据只在 Chrome 扩展提供，并由可选浏览器权限控制；撤销权限后读取的数据会清除。网站版本保留清晰说明和其余首页功能。

## 数据与恢复

- 个人设置、快捷入口、工作区、文件夹和内置工具数据保存在本机浏览器；网站与扩展使用各自的存储空间。
- 快捷入口跨工作区移动时，会解除旧工作区中的文件夹引用，避免入口在目标工作区被隐藏；同工作区编辑保留原有收纳关系和其他成员。
- 打开方式设置保存在本机并纳入 JSON 备份；旧备份缺少这些可选字段时使用原默认值，导入时校验布尔类型。导出下载和备份解析均按需加载。
- 面板筛选和排序只影响临时视图，不改写底层记录顺序，也不改变已有备份格式。
- JSON 备份支持导入预览、按 ID 合并或替换，并涵盖首页小组件、工作区、Dock、壁纸、习惯和计时器等设置。
- 输入和导入数据会经过类型、数量、长度和引用校验；支持跨标签页的本地变更合并，并为存储空间不足提供恢复提示。

## 内置插件接口

面板和首页小组件通过仓库内的 TypeScript 注册表接入，ID、上下文、属性与事件会经过类型检查。面板和小组件按需加载，并提供失败重试。注册表当前只执行仓库内可信模块，不加载远程插件代码，也不提供第三方插件安装与隔离运行能力。

## 质量检查

```sh
npm test
npm run check
npm run build
npm run test:e2e
npm run test:e2e:stable
npm run test:e2e:extension
```

网站浏览器流程覆盖默认 Playwright 浏览器、稳定版 Chrome 与 Edge，以及生产构建预览；扩展流程会构建 Manifest V3 包，并检查新标签页、数据保存和可选权限默认关闭。首屏 JS gzip 预算为 58.5 KiB，全部 JS gzip 为 133.5 KiB；`npm run build` 会自动核验预算和扩展包结构。静态首屏依赖合并打包，避免大量微小共享分块带来的请求和压缩开销；待办、笔记、月历、纪念日、计算器和专注计时共用一个懒加载工具包。相关本地概览、浏览器概览、浏览器工具分别分组，均不提前进入首屏；启用其中一个视图时可下载同组代码，但不会挂载其他组件、读取浏览器数据或申请权限。本地入口查找、其余面板、图片处理和备份解析仍按需加载。

组件测试覆盖待办与笔记的搜索、组合筛选、排序、键盘焦点、Unicode 预览/计数、数量限制及事件，概览组件的空状态和日期切换，以及快捷菜单的循环键盘导航、禁用项跳过和焦点管理。模块加载失败时会隔离错误并提供重试；浏览器缓存失败模块时，可由用户主动选择重新加载页面恢复。

统一的 `SelectField` 保留原生选择框的标签、表单和键盘语义，在支持 `base-select` 的浏览器中增强为主题化顶层菜单；旧浏览器及强制高对比度模式使用原生回退。快捷入口、工作区和 Dock 操作菜单共用上下键/Home/End 导航及禁用项跳过规则，Escape 关闭后恢复触发点焦点。`e2e/ui-refinements.spec.ts` 覆盖三种翻页效果的桌面/手机/短屏稳定布局、下拉框的主题/溢出/Escape/原生回退，以及打开方式持久化、导出和实际导航。

## 尚未提供

当前版本没有账号、云同步、原站通知或远程第三方插件。跨浏览器迁移可通过 JSON 备份完成。
