# Inftab V1.7.0

## 主要更新
- 首页默认隐藏时钟与常驻搜索栏，保留用户既有设置；按快捷键或工具栏打开搜索。
- 连续虚拟循环轨道、基于时间的阻尼吸附、滚轮余量与快速反转；保留粒子和拖尾模式。
- macOS 风格 Dock：邻近放大、动态间距、玻璃底座、自动隐藏、拖拽和键盘 FLIP 排序。
- 快捷入口管理新增工作区联合筛选；原本地配置与数据格式不变。
- 独立网页 PWA 与 MV3 扩展构建；按需离线、SHA-256 完整性验证、保留旧版本标签页、缓存诊断与安装引导。
- 首屏搜索模块按需加载，保持原核心及 PWA 独立性能预算。

## 安装
- 网站： https://weepwood.github.io/inftab-mirror/ ，浏览器支持时可安装，离线模式需主动启用。
- 扩展：解压 extension ZIP，在 chrome://extensions 开启开发者模式并加载解压目录；不新增必选权限。
- 网站 ZIP 可部署至支持 HTTPS 的静态网站，保留相对路径。

## 已知边界
真实触控板、高刷新率设备及所有系统安装提示尚未完成实机认证；网络功能不能离线使用。CSS 弹簧为近似曲线。发布必须通过同一提交的完整 Release validation；CI 数值以该运行日志为准。
