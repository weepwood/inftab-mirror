# V1.4.0 性能专项

状态：发布候选，尚未合并；以准确发布提交的完整 Release validation 成功为准。

- 复用本地搜索索引、规范化文本及评分桶，保持原搜索排序、隐藏入口与共享工具去重规则。
- 缓存文件夹预览、批量管理索引；分离入口映射与排序依赖，优化待办角标与 Dock 查找。
- 每日自动备份在事务内先判断日期标记，再按需创建快照；手动及变更前快照保持原时间点，不改变 IndexedDB v1 与旧备份格式。
- 图标异步解码，稳定翻页 DOM key，粒子采样画布复用，动画画布最多 4 Mi 像素（单个 RGBA8 缓冲约 16 MiB，非浏览器总内存）；超高 DPI 动画可能较柔和。
- 无新增运行时依赖、权限、性能预算或破坏性数据迁移。
