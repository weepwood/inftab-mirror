# Inftab V1.8.0

本版本冻结现有分页式首页架构，作为下一代桌面布局重构前的稳定里程碑。

## 更新
- 首页滑动模式采用固定版本 Swiper 14.4.0 原生 CSS 过渡、循环与 Virtual 模块，移除旧自研逐帧翻页引擎。
- 普通滚轮未达阈值时保持静止；有效输入触发完整过渡，动画中忽略额外滚轮输入。
- 修复首排图标悬浮与键盘焦点裁切，保留外层横向遮罩。
- 保留既有用户数据、快捷入口、文件夹、工作区、Dock、拖拽、菜单、可选粒子和拖尾效果及PWA/MV3。
- Swiper 独立30KiB gzip门禁，其他JS、入口、CSS、PWA预算保持不变，并校验分包模块归属。

## 安装与回退
- 网站：https://weepwood.github.io/inftab-mirror/
- 扩展：解压 extension ZIP，在 chrome://extensions 或 edge://extensions 的开发者模式中加载解压目录。升级前先导出配置备份。
- 网站 ZIP 独立静态部署，保持相对路径。离线需主动开启。
- 两个ZIP和SHA256SUMS.txt由通过同提交完整验收的构建生成，下载后可用 sha256sum -c SHA256SUMS.txt 校验。
- V1.7.0 既有 Tag 和 Release 不覆盖。V2 桌面重构不包含在此版本。

## 已知边界
- 已通过Chromium及Mac Edge专项、线上普通滚轮自动化；实际手动鼠标、高刷新率、Firefox和WebKit仍未完成完整认证。
- 系统减少动态效果或用户设定零时长可能没有过渡。高频滚轮会有输入丢弃；6000帧短时报告不能证明长期无泄漏。
- #29旧引擎耐久分支暂冻结，不得在后续合并恢复旧引擎。最终发布以本次完整 Release validation 为准。
