# Inftab V2.0.0

在 V1.8.0 经典首页的基础上，新增可选的 macOS 风格桌面工作空间。经典模式仍为默认，不强制切换。

## 更新

- 自由桌面：网格吸附、图标多选与组移动、独立工作区位置和布局。
- 窗口管理：多 Finder 窗口、工具单实例、拖动、缩放、左右停靠、最小化、最大化、会话恢复。
- Finder：列表/图标视图、搜索排序、面包屑、最多八层子目录、跨空间子树移动、内部剪贴板、键盘及右键操作、有限撤销/重做。
- Spotlight：搜索快捷入口、标签、文件夹、工作区、笔记与待办，支持精准待办定位。
- Mission Control：窗口概览、空间隔离和移动、基于图标坐标的示意预览，Dock 运行状态。
- 数据保护：恢复点、桌面操作锁、持久化事务意图、明确确认的继续写入/回退及冲突拒绝。
- 保留 V1.8 JSON 数据兼容读取、经典 Swiper、离线 PWA 与 MV3 扩展；备份恢复逻辑按需加载。

## 安装与验证

- 网站：https://weepwood.github.io/inftab-mirror/
- 升级前导出 JSON 备份；通过顶部桌面模式按钮启用新桌面，随时切回经典模式。
- 扩展：解压 extension ZIP，在 Chrome 或 Edge 的开发者模式加载解压目录。网站 ZIP 保持相对路径独立部署。
- 发布仅使用同一 main 提交经完整 Release validation 验证的产物。使用 `sha256sum -c SHA256SUMS.txt` 校验两份 ZIP。保留 V1.8.0 Tag 和 Release。

## 已知边界

- 当前权威存储仍为 localStorage v1，IndexedDB 持久化的是事务恢复意图及备份，不是全数据 ACID 迁移。旧版和普通编辑不受桌面锁全面约束；恢复前请导出备份并关闭其他编辑标签页。真实断电恢复不作保证。
- 窗口与最近命令仅恢复同一标签页会话，工作区预览不是实时截图。内部剪贴板仅支持快捷入口，不递归复制文件夹。撤销不涵盖所有操作，也不跨刷新保留。
- V1.8 可读取旧有入口；旧版重新保存 V2 数据可能丢失目录层级。HTML 导出保留层级，导入仍为平铺预览。
- Firefox/WebKit 验证桌面网站功能；不声称所有扩展功能跨浏览器通用。正式发布以同提交完整验收结果为准。
