# V1.1.0 架构治理与稳定性

状态：发布候选，待 Release validation 完整验证通过。

- 首页布局与导航、快捷入口拖拽和分页、生产力、工作区、备份及并发所有权模块独立。
- 保留全部 v1 存储键、备份格式和功能；不做强制 IndexedDB 迁移。
- 防止损坏的跨标签 JSON 覆盖有效状态；失败写入在生命周期边界有限重试。
- 日常快速 CI、Pages 单次构建与里程碑全量 E2E 分离。
- 统一 npm 包、锁文件和扩展版本为 1.1.0；不扩大扩展权限。

验收：以 main 上对应版本提交的 Release validation 结果为准；未通过不得标记为正式发布。完整测试、包体积校验及验证产物由 GitHub Actions 提供。
