# V1.3.0 个人工作台

状态：发布候选，待准确发布提交的完整 Release validation。

- 工作区独立网格布局，支持继承全局、草稿预览、保存和取消；并发修改时拒绝过时草稿。
- 小组件集中管理：11 种内置组件、目录搜索、启用/移除、预设、排序与尺寸；组件设置全局共享，预览不启动联网组件。
- 快捷入口批量选择、移动、删除、标签增删及筛选；移动/删除先保存本地恢复点。
- Netscape HTML 书签导入预览与安全校验、去重和容量保护；导入到当前工作区并展平目录，导出组织为工作区/文件夹。
- IndexedDB 本地快照：打开首页时每日最多一次、手动及变更前快照，最多 7 条 / 24 MiB，每份最多 8 MiB，历史预览、恢复及 JSON 导出。清理站点数据会影响本地历史，建议定期导出。
- 保留原 localStorage v1 数据及 JSON 备份格式，无新增运行时依赖或浏览器权限。
- 三层验证：普通 PR 快速 CI，数据与核心 UI 按路径执行专项 Chromium，里程碑完整浏览器、生产及 MV3 验收。
- 首屏 JS gzip 上限 60.5 KiB，全部 JS 156 KiB；重型管理模块懒加载。

复验修复：320×360 超矮视口下，布局编辑等新增固定操作按钮可能压缩工作区列表至不可操作。保留全部操作，使用单一面板滚动容器，并在 UI 专项中执行原有三种视口及创建/删除测试；不放宽超时或跳过测试。

正式发布以 main 对应 Release validation 成功为准；Pages 持续部署不代表正式发布，独立 GitHub Release 与商店发布另行执行。
